# 项目总结（项目经验视角）

本文从"一个课程 / 个人项目能说明什么"的角度，记录目标、难点、取舍与结果，
供项目介绍或面试讲述时参考。技术细节见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 1. 一句话

把 MESA 恒星演化模拟的命令行工作流做成了一个桌面操作台：从空白 WSL2 用一条
命令装好，之后建项目、改 inlist、编译、运行、出图、出视频都在图形界面里完成。

## 2. 规模

| 指标 | 数值 |
|---|---|
| Python 源文件 | 41 个（业务与界面） |
| 源码行数 | 约 8,500 行 |
| 测试模块 | 29 个 |
| 测试行数 | 约 9,500 行（测试与源码接近 1:1） |
| 内置参数库 | 4,147 个 MESA 参数 + 全文索引 |
| 离线手册 | MESA 26.4.1 "Using MESA" 全章中英对照 |
| 支持版本 | MESA 24.08.1 + MESA SDK 24.7.1（实机验证） |

## 3. 三个主要难点

### 3.1 环境的不确定性

MESA 用户的环境千奇百怪：`MESA_DIR` 过期、装在 `~/mesa/mesa-24.08.1`、
`/opt/mesa`、或者根本没装；WSL2 里还多一层挂载路径。

做法：不猜。`core/env.py` 把检测结果拆成"路径 + 是否可用 + 证据 + 警告"，
每条结论都能追溯到具体文件（`star/work`、`mesa_data.db`、`build.log`）；
路径失效时按已知布局扫描，并在界面上明确显示"可用 / 不可用 + 路径"，而不是
静默回退到 `~/mesa`。安装器遵循同一原则："已安装就检查，未安装给指引"。

**收获**：不确定的环境下，"给出证据"比"给出结论"更重要。

### 3.2 命令执行的正确性与可观测性

界面上的每个按钮最终都变成 shell 命令。项目名、路径可能含空格、引号、中文，
拼字符串既会出错也是注入面；而"点一下到底执行了什么"必须是可解释的。

做法：命令由 `core/mesa/commands.py` 以 argv 列表构造，需要串联时用 `&&`
连接已转义的段；「按钮 → 命令」的映射被声明为冻结协议，由快照测试固定，
任何行为变化都会在 diff 里显形。

**收获**：把"界面行为"变成"数据 + 快照"，重构才有了安全网。

### 3.3 没有 MESA 也要能测

编译 MESA 要几十分钟、占 20 GB，不可能放进 CI。但解析器、校验器、命令构造
恰恰是最需要回归保护的部分。

做法：两层夹具——`fake_mesa_project/` 用脚本生成一个结构完整的假项目（含假
`mk`/`rn`/`re` 与合成的 `LOGS/`），`real_mesa/` 保存真实运行截取的
`history.data`、`profile2.data`，分别覆盖"链路能跑通"与"真实格式能解析"。

**收获**：测试的可移植性来自接口设计——`core` 不碰 Tk 与 matplotlib，
才能在 5 秒内用标准库跑完。

## 4. 主要取舍

| 取舍 | 决定 | 理由 |
|---|---|---|
| 技术栈 | Python + Tk，而非 Web | 用户就在本机跑 MESA，桌面程序零部署；Web 还要考虑端口、浏览器、文件权限 |
| 是否打包 MESA | 不打包 | 2 GB 且应从官方渠道获取；改为把下载与放置写清楚，并让安装器自动完成 |
| 是否打包字体 | 打包（约 32 MB） | 空白 WSL2 常缺中文字体，Tk 会显示方块；"装完即用"比省仓库体积重要 |
| 重构方式 | 先补测试再改结构 | 功能已在使用，不能为了"架构漂亮"引入回归 |
| 测试框架 | 标准库 unittest | 目标机器可能没有网络或第三方测试依赖，装完就能跑 |

## 5. 结果

- 从空白 WSL2 到能跑第一个恒星模型，只需一条命令加一次下载；
- 29 个测试模块覆盖环境检测、inlist 校验、`LOGS` 解析、命令构造、视频帧校验、
  任务并发与界面装配；
- 分层约束由静态检查强制执行，后续改动不会悄悄把业务逻辑写回界面；
- 文档覆盖安装、架构、测试、下载与排错，新接手的人（包括未来的自己）能快速上手。

## 6. 还可以做得更好

- pgstar 实时绘图窗口在 WSL2 下的显示问题尚未解决（需要处理 X11 / WSLg 的
  窗口映射差异）；
- 语义校验仍是启发式的，可引入 MESA 默认值文件做更严格的类型检查；
- 缺少参数扫描 / 批量运行的编排能力，目前一次只能跑一个模型；
- 界面截图与演示视频尚未补齐，README 目前用架构图代替。
